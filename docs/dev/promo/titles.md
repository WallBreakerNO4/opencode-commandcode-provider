# 三平台标题候选

> NodeSeek 技术区四页实拍总结的规律：【开源】/【实测】/【分享】标签打头；「产品名：一句功能」是标准结构；硬数字（额度、star 数、实测数据）最抓人；痛点疑问句「老被 X 拦？开源了个 Y」是常见爆款句式；整体口语化，忌破折号长叙事腔。

## NodeSeek（推荐主战场，社区本来就在讨论 Command Code / OpenCode Go，点名即懂）

1. `【开源】$1 的 Command Code 订阅没有 API？搓了个 OpenCode 插件直接桥接它`
2. `【实测】$1/月 $10 额度的 Command Code Go，桥接进 OpenCode 里直接用`
3. `搓了个 OpenCode 插件：把 Command Code Go 订阅桥接成原生 provider，40+ 模型开箱即用`
4. `Command Code Go 只能用官方 CLI？写了个插件，在 OpenCode 里直接吃 $1 订阅的 40+ 模型`
5. `【开源】opencode-commandcode：让 Command Code Go 订阅在 OpenCode 里开箱即用，兼容 v1/v2`

- 1 号痛点疑问句 + 口语「搓了个」，和正文开头呼应；2 号借【实测】标签 + 价格数字，适合想突出真实体验；4 号把「40+ 模型」数字放句尾钩子；3、5 号是标准「产品名：功能」结构，最稳。

# 三平台标题候选

同一篇正文，只换标题。每个平台给出候选并附一句理由，发布前选定其一。

## NodeSeek（调性：性价比 / 订阅羊毛，价格钩子最有效）

1. `$1/月的编码订阅给 $10 额度，可惜被锁死在官方 CLI 里——我把它桥接进了 OpenCode`
2. `1.4 刀包月、10 刀额度，终于不用忍官方 CLI 了：OpenCode 插件分享`
3. `这可能是最便宜的 Coding 订阅：$1 得 $10 额度，前提是你得会折腾——我帮你折腾好了`

- 理由：标题里价格和倍率放最前， NodeSeek 用户对"刀"敏感；第 3 个偏口语化，互动率可能更高但略油。

## linux.do（调性：AI 编程工具链 / 分享交流，故事与工具并重）

1. `受不了官方 CLI，我给 Command Code Go 写了个 OpenCode 插件`
2. `在 OpenCode 里直接用上 Command Code Go 订阅（开源插件分享）`
3. `$1 订阅被锁死在官方 CLI？装个插件解锁 40+ 模型`

- 理由：第 1 个第一人称故事感最强，与本站"分享"氛围最合；第 2 个最稳；第 3 个带数字钩子。

## V2EX（调性：克制、技术向，忌标题党）

1. `开源了一个 OpenCode provider 插件：把 Command Code Go 订阅桥接成原生 provider`
2. `opencode-commandcode：让 Command Code Go plan 在 OpenCode 里开箱即用`
3. `把一个"没有 API"的订阅桥接进 OpenCode：协议逆向 + provider 插件`

- 理由：V2EX 不吃营销腔，用平实的开源宣告式标题；第 3 个略带技术钩子，适合想引技术讨论时用。
